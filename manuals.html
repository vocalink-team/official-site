VT-ACC-001 / VERSION 1.0

電子取引データの訂正及び削除の防止に関する事務処理規程

管理責任者：Vocalink-team代表保存先：Google Drive制定：2026年09月12日

第1条（目的）

電子取引に係る取引情報を適正に保存し、正当な理由のない訂正又は削除を防止する。

第2条（適用範囲）

代表者、運営メンバー、業務委託者その他電子取引データを取り扱う者に適用する。

第3条（保存基準）

電子メール、クラウド、Webサービス等で授受する見積書、注文書、契約書、納品書、請求書、領収書その他の取引情報を対象とし、指定Google Driveへ保存する。

第4条（保存方法）

Vocalink-team
└─ 電子取引データ
   └─ 年度
      └─ 案件番号_取引先名_案件名
         ├─ 見積書
         ├─ 契約書
         ├─ 納品書
         ├─ 請求書
         ├─ 領収書
         └─ その他

ファイル名は YYYY-MM-DD_取引先名_取引金額_書類種別.拡張子 を原則とする。

第5条（訂正・削除）

正当な理由のない訂正、上書き、改変又は削除を禁止する。必要な場合は管理責任者へ報告し、理由等を記録する。

第6条（検索・保存期間）

取引年月日、取引先、取引金額等から確認できる状態を維持する。保存期間は関係法令により定められる期間を基本とし、より長い期間が必要な場合はその期間を優先する。

第7条（アクセス・事故）

アクセス権限を必要な範囲に限定し、紛失、誤削除、不正アクセス、情報漏えい等は管理責任者へ報告する。

本規程は2026年09月12日から施行する。

VT-ACC-002 / VERSION 1.1

経理・会計事務マニュアル

管理責任者：Vocalink-team代表電子取引データ：VT-ACC-001参照改訂：2026年09月12日
電子取引データの保存場所、ファイル名、保存期間、訂正・削除、検索、アクセス管理等はVT-ACC-001を参照する。

第1条（基本）

取引の事実、金額、日付、証憑を正確に記録し、私的支出と事業支出を区分する。

第2条（収入・支出）

売上、請求、入金、支出、支払、未収、未払等を記録し、必要な証憑を確認する。

第3条（案件連携）

顧客、案件、見積、契約、請求等を可能な範囲で関連付ける。

第4条（電子証憑）

電子的に受領又は交付した証憑はVT-ACC-001に従って保存する。

第5条（月次・税務）

月次で売上、入金、支出、未収、未払、残高、請求漏れ、支払漏れ等を確認する。税務処理は関係法令に従う。

VT-ACC-003 / VERSION 1.0

見積・請求事務マニュアル

管理責任者：Vocalink-team代表電子取引データ：VT-ACC-001参照制定：2026/09/12

1. 見積

顧客、案件、作業内容、数量、単価、金額、税額、合計、有効期限、支払条件を確認し、見積番号を付与する。

2. 請求

請求条件を満たしたら請求書を発行し、請求先、内容、金額、税額、支払期限、振込先を確認する。

3. 送付・入金

送付先と添付を確認して送信し、入金後に入金日・金額を記録する。期限超過時は確認・報告する。

4. 保存・訂正

電子取引データの保存と訂正・削除はVT-ACC-001に従う。

VT-ACC-004 / VERSION 1.0

支払い・経費管理マニュアル

管理責任者：Vocalink-team代表電子取引データ：VT-ACC-001参照制定・施行：2026/09/12

1. 基本フロー

支出予定 → 申請 → 確認・承認 → 支払い → 記録 → 証憑確認

2. 対象

サーバー・ドメイン、ソフトウェア、制作費、外注・業務委託費、広告費、備品、交通費その他業務上必要な支出を対象とする。

3. 証憑・立替

領収書、請求書、利用明細、注文確認、契約書、銀行振込記録等を確認する。立替は申請・確認・承認・精算を行う。

4. 二重支払・月次

支払前に請求番号、対象期間、支払済みかを確認し、月次で未払・立替・定期支払等を確認する。

電子取引データの保存はVT-ACC-001を参照する。

VT-ACC-005 / VERSION 1.0

契約管理事務処理規程

管理責任者：Vocalink-team代表契約管理：contracts.html電子取引データ：VT-ACC-001参照制定：2026/09/14施行：2026/09/14
位置付け：契約書等の電子データ保存はVT-ACC-001を基準とし、本規程では契約の申請、確認、承認、締結、変更、更新、終了及び管理を定める。

第1条（目的）

Vocalink-teamが締結する契約について、内容を正確に把握し、適切な承認・締結・履行管理・更新・終了を行う。

第2条（適用範囲）

代表者、運営メンバーその他契約業務に関与する者に適用する。

第3条（基本原則）

  1. 締結前に相手方、目的、金額、期間及び重要条件を確認する。
  2. 権限を有する者が締結する。
  3. 契約変更・更新・終了を記録する。
  4. 契約書等の電子データはVT-ACC-001に従う。

第4条（契約の起案）

契約の目的、相手方、契約種別、期間、金額、支払条件、担当者、関連案件等を整理し、契約管理システムへ登録する。

第5条（契約内容の確認）

契約期間・更新条件、報酬・支払条件、納品・検収、秘密保持・個人情報、著作権・知的財産権、損害賠償、解除・解約条件その他重要事項を確認する。

第6条（法務確認）

重要な契約、金額が大きい契約、権利義務に大きな影響を及ぼす契約等は、管理責任者が確認し、必要に応じて専門家へ相談する。

第7条（承認）

契約締結前に必要な承認を受ける。承認者はVocalink-teamの権限体系及び個別の承認ルールに従う。

第8条（契約番号）

契約には契約番号を付与し、契約管理システム、関連案件、見積書及び請求書等との紐付けに利用する。

第9条（締結）

双方の合意が確認できる方法により締結する。電子契約の場合はサービス名及び締結日時等を確認できる状態にする。

第10条（印紙税等）

紙の契約書等について印紙税等が関係する場合は、契約内容に応じて必要な確認を行い、判断が難しい場合は専門家又は関係機関へ確認する。

第11条（保存）

契約書、電子契約データ、契約成立を確認できる記録その他の関連資料を適切に保存する。電子取引データはVT-ACC-001に従う。

第12条（契約管理システム）

契約番号、契約名、契約種別、相手方、開始日、終了日、金額、更新条件、担当者、契約書URL、状態及び履歴等を管理する。

第13条（アクセス管理）

契約情報へのアクセスは業務上必要な範囲に限定し、機密性の高い契約情報を不要な者へ共有しない。

第14条（契約変更）

変更内容、変更理由、変更日及び関係者を確認し、必要に応じて変更契約書等を作成する。変更履歴を記録する。

第15条（更新管理）

契約終了日及び更新通知期限を管理し、更新が必要な契約は期限前に担当者及び管理責任者へ確認する。自動更新契約も更新条件を確認する。

第16条（終了・解約）

終了日、解約理由、相手方への通知、未払・未収、返却物、アカウント停止その他必要な処理を確認し、契約管理システムへ記録する。

第17条（関連業務との連携）

契約は可能な範囲で顧客、営業案件、見積書、制作案件及び請求書と紐付け、契約条件と請求内容に相違がないか確認する。

第18条（契約履行）

契約期間中は、期限、納品、支払、更新条件その他重要な義務の履行状況を確認する。

第19条（事故・不正）

契約書の紛失、誤共有、誤削除、不正アクセス、情報漏えい等を発見した場合は速やかに管理責任者へ報告する。無断締結、無断変更、無断削除・改変を禁止する。

第20条（管理責任者）

契約管理の最終的な管理責任者はVocalink-team代表とする。

第21条（見直し）

法令、事業内容、契約管理方法又はシステムに変更が生じた場合は、本規程を見直す。

附則

本規程は2026年09月14日から施行する。第1.0版として制定する。
