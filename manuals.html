VT-ACC-001 / VERSION 1.0

電子取引データの訂正及び削除の防止に関する事務処理規程

管理責任者：Vocalink-team代表保存先：Google Drive制定：2026年09月12日

第1章　総則

第1条（目的）

本規程は、Vocalink-teamが電子取引を行った場合において、その電子取引に係る取引情報の電磁的記録を適正に保存するために必要な事項を定めるものである。また、電子取引データについて正当な理由のない訂正又は削除が行われることを防止し、電子帳簿保存法その他関係法令に基づく保存義務を適正に履行することを目的とする。

第2条（適用範囲）

本規程は、当チームの業務において電子取引を行う代表者、運営メンバー、業務委託者その他当チームが電子取引データを取り扱うことを認めた者に適用する。

第3条（基本方針）

  1. 電子取引データを適正に保存する。
  2. 保存した電子取引データについて、正当な理由のない訂正又は削除を行わない。
  3. 訂正又は削除が必要となった場合には、その事実及び理由を記録する。
  4. 必要な電子取引データを速やかに確認、提示又は提出できる状態を維持する。
  5. 法令改正及び業務内容の変更に応じて、保存方法及び管理方法を見直す。

第2章　管理体制

第4条（管理責任者）

電子取引データの保存及び管理について、管理責任者を置く。管理責任者はVocalink-team代表とする。

管理責任者は、保存体制の整備、保存場所の決定、本規程の管理、保存状況の確認、訂正・削除の確認、アクセス権限の管理、周知及び税務調査等への対応を行う。

第5条（保存担当者）

管理責任者は、必要に応じて電子取引データの保存担当者を指定できる。保存担当者は管理責任者の指示に従い、電子取引データを適切に保存する。

第3章　電子取引の範囲

第6条（電子取引）

電子メール、クラウドサービス、Webサイト・Webサービス、オンラインストレージ、電子請求書サービス等を利用して取引情報を電子データで授受する取引を対象とする。

第7条（対象となる電子取引データ）

見積書、見積回答、注文書、注文請書、契約書、納品書、請求書、領収書、支払に関する電子データその他取引情報を含む電子データを対象とする。

第4章　保存場所及び保存方法

第8条（保存場所）

正式な保存場所は、Vocalink-teamが指定するGoogle Driveとする。個人端末のみを正式な保存場所としてはならない。

第9条（フォルダ構成）

Vocalink-team
└─ 電子取引データ
   └─ 2026年度
      └─ 案件番号_取引先名_案件名
         ├─ 見積書
         ├─ 契約書
         ├─ 納品書
         ├─ 請求書
         ├─ 領収書
         └─ その他

第10条（電子取引データの保存）

電子取引により取引情報を授受した場合、原則として授受した電子データを保存する。電子メールの添付ファイルやWebサービスから取得したデータも対象とする。

第5章　ファイル名及び管理番号

第11条（ファイル名）

ファイル名は原則として次の形式とする。

YYYY-MM-DD_取引先名_取引金額_書類種別.拡張子

例：
2026-09-01_株式会社ABC_100000_請求書.pdf

第12条（管理番号）

案件番号、見積番号、契約番号、請求書番号等を利用し、電子取引データと各業務システムを関連付けて管理する。

第6章　業務システムとの紐付け

第13条（管理システムとの連携）

電子取引データについて、可能な範囲で見積書管理、契約管理、請求書管理、案件管理その他の業務システムと紐付ける。

案件
  ↓
見積
  ↓
契約
  ↓
納品
  ↓
請求
  ↓
入金

第14条（Google Drive保存先の管理）

必要に応じてGoogle Drive上の保存先又は保存ファイルを管理システムから確認できるようにする。保存先を変更した場合は可能な限り管理システム上の情報も更新する。

第7章　訂正及び削除

第15条（訂正及び削除の禁止）

保存した電子取引データについて、正当な理由なく訂正、上書き、改変又は削除を行ってはならない。

第16条（訂正又は削除が必要な場合）

誤りがあり訂正又は削除が必要となった場合は管理責任者へ報告し、必要性及び方法を確認する。可能な限り、日時、対象データ、実施者、理由、前後の情報、確認結果を記録する。

第17条（誤ったデータを保存した場合）

原則として正しいデータを追加保存し、誤ったデータの削除が必要な場合は第16条の手続に従う。

第8章　検索及び提示

第18条（検索可能な状態の確保）

取引年月日、取引先及び取引金額等により確認できる状態を維持し、可能な限り案件番号、見積番号、契約番号、請求書番号も登録する。

第19条（税務調査等への対応）

税務調査その他法令に基づき確認、提示又は提出を求められた場合は、管理責任者が対応する。

第9章　保存期間

第20条（保存期間）

電子取引データは、所得税法、法人税法、消費税法、電子帳簿保存法その他関係法令により定められる期間保存する。法令上7年間の保存が必要となるデータについては原則7年間保存し、より長い期間が必要な場合はその期間を優先する。

第10章　アクセス管理

第21条（アクセス権限）

電子取引データへのアクセス権限は業務上必要な範囲で付与し、必要以上の権限を付与しない。

第22条（アカウント管理）

  1. アカウントを不必要に共有しない。
  2. 認証情報を第三者へ開示しない。
  3. 不正アクセスが疑われる場合は速やかに管理責任者へ報告する。
  4. 業務上不要となった者のアクセス権限を速やかに停止する。

第23条（退任・契約終了時の対応）

退任又は契約終了となった場合、管理責任者は必要に応じてアクセス権限を停止又は変更する。

第11章　バックアップ及び障害対応

第24条（バックアップ）

保存期間を通じて適切に保存できるよう、必要に応じてバックアップその他の措置を講じる。

第25条（データ消失等）

紛失、破損、誤削除、改変その他の事故を発見した場合は速やかに管理責任者へ報告する。

第26条（システム障害）

Google Driveその他のシステムに障害が発生した場合、障害状況、データへの影響、復旧、保存状態及び再発防止を確認する。

第12章　セキュリティ事故

第27条（不正アクセス等）

不正アクセス、情報漏えい、不正な変更その他のセキュリティ事故が発生した場合は速やかに管理責任者へ報告し、必要な措置を講じる。

第13章　教育及び点検

第28条（周知及び教育）

管理責任者は、電子取引データを取り扱う者に対し、本規程の内容を必要に応じて周知する。

第29条（定期点検）

保存状況、保存場所、ファイル名、案件等との紐付け、削除・改変、アクセス権限及び保存期間を必要に応じて点検する。

第14章　例外及び法令改正

第30条（本規程に定めのない事項）

関係法令、国税庁その他公的機関の公表情報及び当チームのその他の規程に基づき管理責任者が判断する。困難な事項は必要に応じて専門家へ確認する。

第31条（法令改正への対応）

法令改正による影響を確認し、必要に応じて本規程を改定する。

第15章　規程の管理

第32条（規程の改定）

改定時は版数、改定日及び改定内容を記録する。

第33条（規程の保管）

最新版は指定Google Driveその他の管理場所に保存し、必要に応じて旧版も改定履歴として保存する。

第34条（規程の優先）

本規程と関係法令の内容が異なる場合には、関係法令を優先する。

附則

第1条（施行） 本規程は2026年09月12日から施行する。

第2条（初版） 本規程は第1.0版として制定する。

第3条（見直し） 法令改正、事業内容・電子取引方法・保存システムの変更、運用上の問題等に応じて必要に応じて見直す。

VT-ACC-002 / VERSION 1.0

経理・会計事務マニュアル

管理責任者：Vocalink-team代表証憑保存：Google Drive制定：2026年09月12日

第1章　総則

第1条（目的）

本マニュアルは、Vocalink-teamにおける収入、支出、請求、入金、支払、証憑及び会計関連データの処理方法を定め、経理業務を正確かつ統一的に行うことを目的とする。

第2条（適用範囲）

経理及び会計に関係する代表者、運営メンバーその他当チームが指定する者に適用する。

第3条（基本原則）

  1. 取引の事実に基づいて処理する。
  2. 金額及び日付を正確に記録する。
  3. 取引に関する証憑を適切に保存する。
  4. 電子取引データはVT-ACC-001に従う。
  5. 不明な取引は管理責任者へ確認する。
  6. 私的支出と事業上の支出を区分する。
  7. 不正な経理処理、架空取引及び虚偽記録を行わない。

第2章　経理管理体制

第4条（管理責任者）

経理及び会計の管理責任者はVocalink-team代表とする。経理処理、支出・支払、売上・入金、請求書、証憑、会計データ及び税理士等への相談を管理する。

第5条（経理担当者）

管理責任者は必要に応じて経理担当者を指定できる。重要な支出、異常な取引その他判断が必要な事項は管理責任者へ報告する。

第3章　取引の基本管理

第6条（取引の記録）

収入及び支出は可能な限り速やかに記録し、取引日、取引先、取引内容、金額、区分、支払・入金方法、案件番号、証憑、備考等を管理する。

第7条（案件との紐付け）

事業に関する取引は可能な限り案件番号を付与し、案件管理システムと経理情報を紐付ける。

第4章　収入管理

第8条（売上の発生）

Webサイト制作、Webコンテンツ制作、システム開発、保守その他の業務の対価を収入として適切に記録する。

第9条（請求書の発行）

請求が必要な取引は請求書管理システムを利用して発行し、請求書番号を付与して案件及び契約等と紐付ける。

第10条（入金確認）

入金予定日を管理し、入金確認後に実際の入金日及び入金額を記録する。差額や期限超過があれば原因を確認する。

第5章　支出管理

第11条（支出の基本原則）

事業に必要な支出について内容及び金額を記録し、証憑を保存する。私的支出を当チームの経費として処理してはならない。

第12条（支出申請）

当チームの費用を支出する場合、必要に応じて事前申請する。申請時は支出予定日、支出先、内容、金額、理由、関係案件、添付資料等を記載する。

第13条（立替払い）

メンバーが業務のために立替払いをした場合、必要な証憑を提出して精算を受ける。支出内容、日付、金額、支払先、必要性及び証憑を確認する。

第6章　証憑管理

第14条（証憑）

領収書、請求書、レシート、見積書、契約書、注文書、納品書、支払明細、銀行取引明細その他取引の事実を確認できる資料を保存する。

第15条（電子証憑）

電子的に受領又は交付した証憑はVT-ACC-001に従って保存する。

第16条（Google Driveへの保存）

正式な保存場所は指定Google Driveとし、原則として年度・案件・書類種別で管理する。

Vocalink-team
└─ 電子取引データ
   └─ 2026年度
      └─ PJ-2026-001_取引先名_案件名
         ├─ 見積書
         ├─ 契約書
         ├─ 納品書
         ├─ 請求書
         ├─ 領収書
         └─ その他

第17条（ファイル名）

電子取引データは原則として YYYY-MM-DD_取引先名_取引金額_書類種別.拡張子 で保存する。

第7章　見積・契約・請求との連携

第18条（見積管理）

見積書は顧客及び案件と紐付け、見積番号を付与し、内容・金額・有効期限を確認して発行する。

第19条（契約管理）

契約締結後は契約管理システムへ登録し、契約番号、案件、顧客、契約期間、更新期限、契約金額等を管理する。

第20条（請求管理）

請求書を発行した場合は請求書管理システムへ登録し、顧客、案件、見積、契約、請求及び入金を関連付ける。

第8章　支払管理

第21条（支払）

支払前に支払先、金額、内容、期限、証憑、必要性及び二重支払でないことを確認する。

第22条（支払記録）

支払日、支払額及び支払先を記録し、電子的な支払については取引明細等を必要に応じて保存する。

第9章　口座及び現金管理

第23条（事業用口座）

事業に関する入出金は可能な限り事業用として管理する口座を利用し、私的資金と混在した場合は適切に区分する。

第24条（現金）

現金による収入又は支出は内容及び金額を記録し、必要に応じて実際の残高と帳簿上の残高を確認する。

第10章　会計システム

第25条（会計データの登録）

収入及び支出を使用する会計システムへ適切に登録し、取引日、金額、取引先及び内容を確認する。

第26条（会計データの修正）

誤りを発見した場合は速やかに確認し、必要な修正を行う。重要な修正は内容及び理由を記録する。

第11章　月次確認

第27条（月次確認）

必要に応じて月単位で売上、入金、未収金、支出、未払金、預金・現金残高、請求漏れ、支払漏れ、証憑保存状況を確認する。

第28条（未入金の確認）

入金予定日を経過した取引について未入金状況を確認し、長期間入金がない場合は管理責任者が対応方針を決定する。

第29条（未払の確認）

支払期限が到来又は近づいている支出について支払状況を確認する。

第12章　税務及び申告

第30条（税務処理）

税務上の処理は関係法令に基づいて行い、判断が困難な事項は必要に応じて税理士その他の専門家へ相談する。

第31条（税務申告）

必要な税務申告は法令上の期限までに適切に行い、必要な帳簿・証憑等を準備する。

第13章　個人情報及び機密情報

第32条（情報管理）

顧客情報、取引先情報、銀行情報その他の機密情報を適切に管理し、業務上必要のない者へ開示してはならない。

第33条（Google Driveのアクセス管理）

経理関連データは業務上必要な者に限りアクセス権限を付与し、不要となった権限は速やかに見直す。

第14章　誤り及び不正への対応

第34条（経理処理の誤り）

誤りを発見した場合は速やかに管理責任者へ報告し、必要に応じて会計データ等を修正する。

第35条（不正の疑い）

架空取引、私的流用、証憑の偽造、金額の不正変更その他の不正が疑われる場合は速やかに管理責任者へ報告する。

第15章　電子取引データとの関係

第36条（電子取引データ保存規程との関係）

電子取引データの保存、訂正、削除及び管理についてはVT-ACC-001を適用する。本マニュアルと同規程の内容が異なる場合、電子取引データの保存に関する事項は同規程を優先する。

第16章　システム障害及びデータ消失

第37条（システム障害）

会計、請求書、Google Driveその他の業務システムに障害が発生した場合は管理責任者へ報告し、必要に応じて代替手段で記録し、復旧後に正式なシステムへ反映する。

第38条（データ消失）

経理データ又は電子取引データの消失を確認した場合は速やかに報告し、可能な範囲でバックアップ等から復旧する。

第17章　文書管理

第39条（マニュアルの管理）

最新版は指定Google Driveその他の管理場所に保存し、必要に応じて旧版を改定履歴として保存する。

第40条（改定）

法令改正、事業内容、会計システム、見積・契約・請求システム、Google Driveの管理方法又は運用上の問題に応じて見直す。

第18章　附則

第1条（施行） 本マニュアルは2026年09月12日から施行する。

第2条（初版） 本マニュアルは第1.0版として制定する。

第3条（見直し） 法令、税務上の取扱い、システム、事業内容その他の変更に応じて必要に応じて見直す。

STANDARD WORKFLOW

経理・取引の標準フロー

01　問い合わせ顧客からの相談を受け、案件を登録する。
02　見積見積番号を付与し、見積書を作成・保存する。
03　契約契約番号を付与し、契約書と案件を関連付ける。
04　制作・納品案件を進行し、必要な納品関係データを保存する。
05　請求請求書番号を付与して請求書を発行・保存する。
06　入金確認入金日・入金額を確認し、会計へ反映する。

電子取引データの保存チェック

  1. 電子データを受領・交付したか確認
  2. Google Driveの適切な案件フォルダへ保存
  3. ファイル名を統一
  4. 案件・見積・契約・請求番号を紐付け
  5. 必要な検索情報を管理
  6. 正当な理由のない削除・改変をしない
