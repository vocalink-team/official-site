VT-ACC-001 / VERSION 1.0

電子取引データの訂正及び削除の防止に関する事務処理規程

管理責任者：Vocalink-team代表保存先：Google Drive制定：2026年09月12日

第1章　総則

第1条（目的）

電子取引に係る取引情報を適正に保存し、正当な理由のない訂正又は削除を防止する。

第2条（適用範囲）

代表者、運営メンバー、業務委託者その他電子取引データを取り扱う者に適用する。

第3条（基本方針）

  1. 電子取引データを適正に保存する。
  2. 正当な理由のない訂正・削除を行わない。
  3. 必要なデータを確認・提示できる状態を維持する。
  4. 法令改正等に応じて管理方法を見直す。

第2章　保存基準

第4条（管理責任者）

管理責任者はVocalink-team代表とする。

第5条（対象データ）

電子メール、クラウド、Webサービス等で授受する見積書、注文書、契約書、納品書、請求書、領収書、支払関係データその他の取引情報を対象とする。

第6条（保存場所）

正式な保存場所はVocalink-teamが指定するGoogle Driveとし、個人端末のみを正式な保存場所としてはならない。

第7条（フォルダ構成）

Vocalink-team
└─ 電子取引データ
   └─ 年度
      └─ 案件番号_取引先名_案件名
         ├─ 見積書
         ├─ 契約書
         ├─ 納品書
         ├─ 請求書
         ├─ 領収書
         └─ その他

第8条（ファイル名）

YYYY-MM-DD_取引先名_取引金額_書類種別.拡張子を原則とする。

第9条（管理番号・紐付け）

案件番号、見積番号、契約番号、請求書番号等を利用し、電子取引データと業務システムを関連付ける。

第10条（訂正・削除）

正当な理由のない訂正、上書き、改変又は削除を禁止する。訂正・削除が必要な場合は管理責任者へ報告し、理由等を記録する。

第11条（検索・提示）

取引年月日、取引先、取引金額等から確認できる状態を維持し、税務調査等への対応は管理責任者が行う。

第12条（保存期間）

所得税法、法人税法、消費税法、電子帳簿保存法その他関係法令により定められる期間保存する。より長い保存期間が必要な場合はその期間を優先する。

第13条（アクセス・事故対応）

アクセス権限を業務上必要な範囲に限定し、紛失、誤削除、不正アクセス、情報漏えい等を発見した場合は管理責任者へ報告する。

第14条（バックアップ・点検）

必要に応じてバックアップ等の措置を講じ、保存状況、アクセス権限、訂正・削除等を点検する。

附則

本規程は2026年09月12日から施行する。第1.0版として制定する。

VT-ACC-002 / VERSION 1.1

経理・会計事務マニュアル

管理責任者：Vocalink-team代表電子取引データ：VT-ACC-001参照改訂：2026年09月12日
保存ルール：電子取引データの保存場所、フォルダ構成、ファイル名、保存期間、訂正・削除、検索、アクセス管理、バックアップ及び事故対応はVT-ACC-001を参照する。本マニュアルでは詳細を重複して定めない。

第1章　総則

第1条（目的）

収入、支出、請求、入金、支払、証憑及び会計関連データを正確かつ統一的に処理する。

第2条（基本原則）

  1. 取引の事実に基づいて処理する。
  2. 金額・日付を正確に記録する。
  3. 証憑を適切に管理する。
  4. 電子取引データはVT-ACC-001に従う。
  5. 私的支出と事業支出を区分する。

第2章　取引管理

第3条（取引記録）

取引日、取引先、内容、金額、区分、支払・入金方法、案件番号、証憑等を記録する。

第4条（案件紐付け）

可能な限り案件番号を付与し、案件管理と経理情報を紐付ける。

第3章　収入管理

第5条（売上）

Web制作、Webコンテンツ制作、システム開発、保守その他の業務対価を適切に記録する。

第6条（請求・入金）

請求書管理システムで請求書を発行・管理し、入金後に実際の入金日・金額を記録する。

第4章　支出管理

第7条（支出）

事業に必要な支出について内容・金額を記録し、証憑を管理する。

第8条（支出申請・立替）

必要に応じて事前申請し、立替の場合は証憑を確認して精算する。

第5章　証憑管理

第9条（証憑）

領収書、請求書、レシート、見積書、契約書、注文書、納品書、支払明細、銀行取引明細等を確認・管理する。

第10条（電子証憑）

電子的に受領又は交付した証憑はVT-ACC-001に従って保存する。

第11条（保存ルールの参照）

電子取引データの保存場所、ファイル名、保存期間、訂正・削除、検索及びアクセス管理についてはVT-ACC-001を参照する。

第6章　見積・契約・請求

見積、契約、請求をそれぞれの管理システムで管理し、顧客・案件・番号を可能な範囲で関連付ける。

第7章　支払・会計

支払前に支払先、金額、内容、期限、証憑及び二重支払の有無を確認する。会計システムへ収入・支出を登録し、誤りは確認のうえ修正する。

第8章　月次・税務

売上、入金、未収、支出、未払、残高、請求漏れ、支払漏れ等を確認する。税務処理・申告は関係法令に従い、必要に応じて専門家へ相談する。

第9章　不正・障害

不正、私的流用、虚偽記録等が疑われる場合は管理責任者へ報告する。システム障害時は代替記録を行い、復旧後に正式システムへ反映する。電子取引データについてはVT-ACC-001を参照する。

附則

本マニュアルは2026年09月12日から施行する。第1.1版として改訂する。

VT-ACC-003 / VERSION 1.0

見積・請求事務マニュアル

管理責任者：Vocalink-team代表電子取引データ：VT-ACC-001参照制定：2026/09/12

1.目的

見積書・請求書の作成、発行、送付及び入金管理を正確に行う。

2.見積作成

顧客、案件、作業内容、数量、単価、金額、税額、合計、有効期限、支払条件を確認し、見積番号を付与する。

3.請求書発行

請求条件を満たしたら請求書管理システムで発行し、請求先、内容、金額、税額、支払期限、振込先を確認する。

4.送付・入金

送付先と添付を確認して送信し、入金後に入金日・金額を記録する。期限超過時は確認・報告する。

5.電子データ保存

請求書等の電子取引データの保存場所、ファイル名、保存期間、訂正・削除、検索、アクセス管理等はVT-ACC-001を参照する。

6.二重請求・訂正

発行前に重複請求がないか確認する。誤りがある場合は訂正方法を確認し、電子取引データの訂正・削除はVT-ACC-001に従う。

7.関連システム

顧客管理、営業案件、見積書、契約、制作案件、請求書の各システムを必要に応じて連携する。

8.管理責任者

最終的な管理責任者はVocalink-team代表とする。

VT-ACC-004 / VERSION 1.0

支払い・経費管理マニュアル

管理責任者：Vocalink-team代表電子取引データ：VT-ACC-001参照制定：2026/09/12施行：2026/09/12

1.目的

経費の発生から申請、承認、支払い、記録、証憑管理までを統一する。

2.対象

サーバー・ドメイン、ソフトウェア、制作費、外注・業務委託費、広告費、備品、交通費その他業務上必要な支出を対象とする。

3.基本フロー

支出予定 → 申請 → 確認・承認 → 支払い → 記録 → 証憑確認

4.申請・承認

申請者、支出先、内容、金額、予定日、目的、案件、証憑等を記録し、必要な支出は事前承認を受ける。

5.証憑

領収書、請求書、利用明細、注文確認、契約書、銀行振込記録等を確認する。電子的に授受した証憑の保存はVT-ACC-001を参照する。

6.立替・外注・定期支払

立替は申請・確認・承認・精算、外注費は契約と請求内容の確認、定期支払は利用状況と契約状況の確認を行う。

7.二重支払・訂正

支払前に請求番号、対象期間、支払済みかを確認する。電子取引データの訂正・削除はVT-ACC-001に従う。

8.月次確認

支出総額、未払、立替、定期支払、高額支出、未処理経費等を確認する。電子取引データの保存状態はVT-ACC-001を参照する。

9.不正・責任

虚偽申請、証憑改ざん、架空取引等を禁止し、不適切な支出は管理責任者へ報告する。最終責任者はVocalink-team代表とする。
